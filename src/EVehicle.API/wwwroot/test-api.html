📝 API Endpoints đã tạo

Leads API

  • PUT /api/leads/{id}/status - UC44: Cập nhật trạng thái Lead

Orders API

  • POST /api/orders - UC28: Staff tạo đơn hàng
  • GET /api/orders/{id} - Lấy chi tiết đơn hàng
  • POST /api/orders/payment - UC28: Tạo thanh toán
  • POST /api/orders/payment/webhook - UC28: Webhook xử lý thanh toán

Contracts API

  • GET /api/contracts/templates - UC43: Lấy danh sách mẫu hợp đồng
  • POST /api/contracts - UC43: Staff tạo hợp đồng từ mẫu
  • GET /api/contracts/{id} - Lấy chi tiết hợp đồng
  • POST /api/contracts/{id}/sign - UC29: Ký hợp đồng
  • GET /api/contracts/{id}/pdf - Tải xuống PDF hợp đồng

Posts API (Member)

  • GET /api/posts/my-posts - UC13: Lấy danh sách bài đăng của user
  • PUT /api/posts/{id} - UC07: Chỉnh sửa bài đăng
  • DELETE /api/posts/{id} - UC08: Xóa bài đăng
  • PATCH /api/posts/{id}/toggle-active - UC09: Tạm ẩn/Hiện bài đăng
